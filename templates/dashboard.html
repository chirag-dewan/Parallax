What This Means

Behavioral Shift carries the system. T2-006 contributes +0.287 delta — more than all other detectors combined (+0.226). Without it, the system would be near-random. This is a single point of failure: if an attacker maintains consistent behavior over time, the primary signal vanishes.

Host Fan-Out is the second leg. T1-009 at +0.131 detects lateral movement through destination diversity. It works because compromised users in LANL touch more hosts. But the 9-topic-bucket ceiling in the adapter caps resolution — with real host-level data this could be stronger.

Everything else is noise. T1-008, T1-007, T1-004 contribute +0.008 to +0.051 — barely above zero. Seven detectors are actively anti-correlated: normal users trigger them more than compromised ones. These were designed for API abuse patterns (token ratios, model targeting, automation signatures) that don't map to authentication data.

The real gap: no content signal, no network flow data, no process telemetry. Auth metadata alone is a narrow aperture. The next gain comes from fusing additional data sources (flows, process starts, DNS), not from tuning these 5 detectors.
